Lesson 0016: Future Plans

Target time: 5-10 minutes. Mission link: make a clear plan for the next visit or service activity.

Tangible win for today: You can say what you are going to do, invite a partner, set a time, and confirm the plan.

Knowledge (keep it light)

Focused concept: the practical frame vamos a for going to do something.

Memorize this mini-exchange:

  1. Manana vamos a visitar a Ana.
  2. Quieres venir con nosotros?
  3. Si, puedo ir a las cuatro.
  4. Perfecto, nos vemos manana.

Reference sheet: Future Plans

Guided practice (retrieval)

Say each line out loud from memory before looking back up:

Prompt A

Tomorrow we are going to visit Ana.

Prompt B

Do you want to come with us?

Prompt C

Yes, I can go at four.

Prompt D

Perfect, see you tomorrow.

Change the name and time to make a real plan.

End-of-lesson assessment

Type each answer from memory. Mastery target for this lesson: 4/4.

Primary source for this lesson

Practice future plans aloud with SpanishPod101, then use a real calendar.

Why this source: structured, beginner-friendly, and practical for quick daily sessions.

Spaced follow-up (tomorrow, 3 minutes)

  • Say your next real plan aloud twice.
  • Invite someone using the second line.
  • Review any missed line and confirm the time.
Ask follow-up questions: Ask your teacher-agent for a planning phone call roleplay.
