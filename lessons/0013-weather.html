Lesson 0013: Weather

Target time: 5-10 minutes. Mission link: make small talk and plan around the weather.

Tangible win for today: You can ask about the weather, describe today, suggest a jacket, and agree warmly.

Knowledge (keep it light)

Focused concept: the useful frame hace for weather conditions.

Memorize this mini-exchange:

  1. Que tiempo hace hoy?
  2. Hace calor y hay sol.
  3. Vamos a llevar una chaqueta?
  4. Si, buena idea.

Reference sheet: Weather

Guided practice (retrieval)

Say each line out loud from memory before looking back up:

Prompt A

What is the weather like today?

Prompt B

It is hot and sunny.

Prompt C

Shall we bring a jacket?

Prompt D

Yes, good idea.

Change calor to frio or lluvia. Say the exchange before leaving home.

End-of-lesson assessment

Type each answer from memory. Mastery target for this lesson: 4/4.

Primary source for this lesson

Use SpanishPod101 for listening and short dialogues, then describe the weather outside in one breath.

Why this source: structured, beginner-friendly, and practical for quick daily sessions.

Spaced follow-up (tomorrow, 3 minutes)

  • Describe the weather at breakfast and lunch.
  • Swap one condition and repeat the exchange.
  • Review any missed line before a visit.
Ask follow-up questions: Ask your teacher-agent for a weather small-talk drill.
