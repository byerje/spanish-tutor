Lesson 0002: Names and Where You Are From

Target time: 5-10 minutes. Mission link: keep a first conversation moving with simple personal questions.

Tangible win for today: You can ask someone’s name, say your name, ask where they are from, and say where you are from.

Knowledge (keep it light)

Memorize this mini-exchange:

  1. Como se llama usted?
  2. Me llamo [your name].
  3. De donde es usted?
  4. Soy de [your place].

Reference sheet: Names and Origins

Guided practice (retrieval)

Say each line out loud from memory before looking back up:

Prompt A

What is your name? (formal)

Prompt B

My name is [your name].

Prompt C

Where are you from? (formal)

Prompt D

I am from [your place].

Then run the exchange twice: once slowly, and once at a natural conversational speed.

End-of-lesson assessment

Type each answer from memory. Mastery target for this lesson: 4/4.

Primary source for this lesson

Continue with the early lessons of Language Transfer: Complete Spanish. Repeat any useful question-and-answer patterns out loud.

Why this source: free, structured, speech-first, and practical for quick daily sessions.

Spaced follow-up (tomorrow, 3 minutes)

  • Say the four-line exchange from memory twice.
  • Include your real name and hometown in the answers.
  • Review any missed line, then repeat the full exchange once more.
Ask follow-up questions: Ask your teacher-agent for pronunciation help, a speed drill, or a roleplay with a friendly stranger.
