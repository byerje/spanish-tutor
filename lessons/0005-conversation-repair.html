Lesson 0005: Conversation Repair

Target time: 5-10 minutes. Mission link: keep real conversations moving when Spanish is too fast or unclear.

Tangible win for today: You can say that you do not understand, ask someone to repeat, request slower speech, and say that you understand.

Knowledge (keep it light)

Memorize this mini-exchange:

  1. No entiendo.
  2. Puede repetir, por favor?
  3. Puede hablar mas despacio?
  4. Ahora entiendo.

Reference sheet: Conversation Repair

Guided practice (retrieval)

Say each line out loud from memory before looking back up:

Prompt A

I do not understand.

Prompt B

Can you repeat, please?

Prompt C

Can you speak more slowly?

Prompt D

Now I understand.

Practice the sequence with a deliberately fast reading, then use the repair phrases until the exchange is clear.

End-of-lesson assessment

Type each answer from memory. Mastery target for this lesson: 4/4.

Primary source for this lesson

Continue with the early lessons of Language Transfer: Complete Spanish. Repeat the phrases out loud at both normal and slower speeds.

Why this source: free, structured, speech-first, and practical for quick daily sessions.

Spaced follow-up (tomorrow, 3 minutes)

  • Say all four repair phrases from memory twice.
  • Use each phrase once during a short practice conversation.
  • Review any missed line, then repeat the full sequence once more.
Ask follow-up questions: Ask your teacher-agent for a listening challenge, a slower-speed drill, or a roleplay where you need clarification.
