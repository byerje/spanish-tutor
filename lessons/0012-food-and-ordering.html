Lesson 0012: Food and Ordering

Target time: 5-10 minutes. Mission link: order simply and offer food or water to a guest.

Tangible win for today: You can ask for a menu item, request water, ask the price, and thank the server.

Knowledge (keep it light)

Focused concept: quiero for a clear, polite desire.

Memorize this mini-exchange:

  1. Quiero una sopa, por favor.
  2. Tambien quiero agua.
  3. Cuanto cuesta?
  4. Gracias, esta muy bien.

Reference sheet: Food and Ordering

Guided practice (retrieval)

Say each line out loud from memory before looking back up:

Prompt A

I want a soup, please.

Prompt B

I also want water.

Prompt C

How much does it cost?

Prompt D

Thank you, that is very good.

Swap sopa for cafe, pan, or fruta. Order three real items aloud.

End-of-lesson assessment

Type each answer from memory. Mastery target for this lesson: 4/4.

Primary source for this lesson

Practice spoken food phrases with SpanishPod101, then say them while looking at a menu.

Why this source: structured, beginner-friendly, and practical for quick daily sessions.

Spaced follow-up (tomorrow, 3 minutes)

  • Place a pretend order using three different foods.
  • Ask and answer the price question twice.
  • Review any missed line before a real meal.
Ask follow-up questions: Ask your teacher-agent for a market or cafe roleplay.
