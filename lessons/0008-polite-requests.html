Lesson 0008: Polite Requests

Target time: 5-10 minutes. Mission link: make simple requests with courtesy during everyday service.

Tangible win for today: You can ask for water, ask for help, ask permission to enter, and thank someone.

Knowledge (keep it light)

Memorize this mini-exchange:

  1. Me puede dar agua, por favor?
  2. Me puede ayudar?
  3. Podemos pasar?
  4. Muchas gracias.

Reference sheet: Polite Requests

Guided practice (retrieval)

Say each line out loud from memory before looking back up:

Prompt A

Can you give me water, please?

Prompt B

Can you help me?

Prompt C

Can we come in?

Prompt D

Thank you very much.

Use a friendly voice and a small pause before por favor. Repeat the requests twice.

End-of-lesson assessment

Type each answer from memory. Mastery target for this lesson: 4/4.

Primary source for this lesson

Continue with the beginner lessons at SpanishPod101. Repeat each request with a natural polite tone.

Why this source: structured, beginner-friendly, and practical for quick daily sessions.

Spaced follow-up (tomorrow, 3 minutes)

  • Say the four requests from memory twice.
  • Practice with objects around you.
  • Review any missed line, then repeat the exchange.
Ask follow-up questions: Ask your teacher-agent for a store, home, or mission-office request roleplay.
