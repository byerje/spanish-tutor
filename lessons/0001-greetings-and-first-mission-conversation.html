Lesson 0001: Greetings and First Mission Conversation

Target time: 5-10 minutes. Mission link: begin understandable spoken interactions from day one.

Tangible win for today: You can greet someone, ask how they are, introduce yourselves as missionaries, and ask permission to share a message.

Knowledge (keep it light)

Memorize this mini-sequence:

  1. Buenos dias. Mucho gusto.
  2. Como esta usted?
  3. Somos misioneros de La Iglesia de Jesucristo de los Santos de los Ultimos Dias.
  4. Podemos compartir un mensaje de Jesucristo?

Reference sheet: Core Greetings and Mission Openers

Guided practice (retrieval)

Say each line out loud from memory before looking back up:

Prompt A

Good morning. Nice to meet you.

Prompt B

How are you? (formal)

Prompt C

We are missionaries of The Church of Jesus Christ of Latter-day Saints.

Prompt D

Can we share a message of Jesus Christ?

Flashcards (optional)

You will see the English prompt. Type the Spanish, then click Check.

End-of-lesson assessment

Type each answer from memory. Mastery target for this lesson: 4/4.

Primary source for this lesson

Listen to and repeat short Spanish speech patterns from SpanishPod101. Start with the beginner lessons and repeat out loud.

Why this source: structured, beginner-friendly, and practical for quick daily sessions.

Spaced follow-up (tomorrow, 3 minutes)

  • Say the 4-line sequence from memory twice.
  • If you miss a line, check the reference sheet, then repeat full sequence once more.
Ask follow-up questions: Ask your teacher-agent anything unclear, including pronunciation, speed drills, or roleplay for this exact exchange.
