Lesson 0011: Family

Target time: 5-10 minutes. Mission link: ask about family and show sincere interest.

Tangible win for today: You can ask who is in a family, name a brother or sister, and respond warmly.

Knowledge (keep it light)

Focused concept: simple family questions and the word tiene for has.

Memorize this mini-exchange:

  1. Tiene hermanos?
  2. Si, tengo un hermano.
  3. Como se llama?
  4. Se llama Luis. Es muy amable.

Reference sheet: Family

Guided practice (retrieval)

Say each line out loud from memory before looking back up:

Prompt A

Do you have siblings?

Prompt B

Yes, I have one brother.

Prompt C

What is his name?

Prompt D

His name is Luis. He is very kind.

Replace brother with sister, mother, or father and repeat twice.

End-of-lesson assessment

Type each answer from memory. Mastery target for this lesson: 4/4.

Primary source for this lesson

Use the SpanishPod101 beginner lessons for spoken repetition and listen for family vocabulary.

Why this source: structured, beginner-friendly, and practical for quick daily sessions.

Spaced follow-up (tomorrow, 3 minutes)

  • Describe two real family members aloud.
  • Ask and answer the four questions without reading.
  • Review any missed line, then repeat with a new name.
Ask follow-up questions: Ask your teacher-agent for a respectful family roleplay.
