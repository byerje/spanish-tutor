Lesson 0007: Places and Directions

Target time: 5-10 minutes. Mission link: ask where a place is and understand a few basic directions.

Tangible win for today: You can ask where a church or bathroom is and understand left, right, and straight ahead.

Knowledge (keep it light)

Memorize this mini-exchange:

  1. Donde esta la iglesia?
  2. Esta cerca de aqui.
  3. Siga derecho y doble a la derecha.
  4. El bano esta a la izquierda.

Reference sheet: Places and Directions

Guided practice (retrieval)

Say each line out loud from memory before looking back up:

Prompt A

Where is the church?

Prompt B

It is near here.

Prompt C

Go straight and turn right.

Prompt D

The bathroom is on the left.

Point while speaking: straight, right, left. Then give the directions twice.

End-of-lesson assessment

Type each answer from memory. Mastery target for this lesson: 4/4.

Primary source for this lesson

Continue with the beginner lessons at SpanishPod101. Repeat each direction phrase while pointing.

Why this source: structured, beginner-friendly, and practical for quick daily sessions.

Spaced follow-up (tomorrow, 3 minutes)

  • Ask and answer the four-line direction exchange twice.
  • Use a real room or street as your map.
  • Review any missed line, then repeat the directions.
Ask follow-up questions: Ask your teacher-agent for a map roleplay or a listening drill with changing directions.
