Lesson 0020: Integrated Conversation Review

Target time: 5-10 minutes. Mission link: carry a warm conversation from greeting through a simple invitation.

Tangible win for today: You can ask about a person, respond about yesterday, make a plan, and share one gospel statement.

Knowledge (keep it light)

Focused concept: connect familiar phrases smoothly instead of translating each word.

Memorize this mini-exchange:

  1. Como esta su familia?
  2. Ayer hablamos y fue un buen dia.
  3. Manana podemos vernos a las cuatro?
  4. Si, y podemos compartir un mensaje.

Reference sheet: Integrated Conversation Review

Guided practice (retrieval)

Say each line out loud from memory before looking back up:

Prompt A

How is your family?

Prompt B

Yesterday we talked and it was a good day.

Prompt C

Can we see each other tomorrow at four?

Prompt D

Yes, and we can share a message.

Roleplay the full exchange twice. Keep going if one word is missing.

End-of-lesson assessment

Type each answer from memory. Mastery target for this lesson: 4/4.

Primary source for this lesson
