Lesson 0009: Time and Appointments

Target time: 5-10 minutes. Mission link: make a simple plan and confirm when to meet.

Tangible win for today: You can ask what time works, suggest tomorrow, confirm an hour, and say see you then.

Knowledge (keep it light)

Memorize this mini-exchange:

  1. A que hora nos vemos?
  2. Manana esta bien?
  3. A las tres de la tarde.
  4. Nos vemos entonces.

Reference sheet: Time and Appointments

Guided practice (retrieval)

Say each line out loud from memory before looking back up:

Prompt A

What time will we see each other?

Prompt B

Is tomorrow okay?

Prompt C

At three in the afternoon.

Prompt D

See you then.

Change the day and time to make a real plan. Say the exchange twice.

End-of-lesson assessment

Type each answer from memory. Mastery target for this lesson: 4/4.

Primary source for this lesson

Continue with the early lessons of Language Transfer: Complete Spanish. Repeat the exchange while pointing to a real calendar time.

Why this source: free, structured, speech-first, and practical for quick daily sessions.

Spaced follow-up (tomorrow, 3 minutes)

  • Make and say one real appointment twice.
  • Change the time and repeat.
  • Review any missed line, then confirm the plan.
Ask follow-up questions: Ask your teacher-agent for a calendar roleplay or a listening drill with times.
