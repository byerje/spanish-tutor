Lesson 0019: Simple Gospel Vocabulary

Target time: 5-10 minutes. Mission link: name a few core gospel ideas in a clear, respectful way.

Tangible win for today: You can say that God loves us, Jesus Christ helps us, and ask whether someone would like to learn more.

Knowledge (keep it light)

Focused concept: short, complete gospel statements without deep grammar theory.

Memorize this mini-exchange:

  1. Dios nos ama.
  2. Jesucristo nos ayuda.
  3. La fe trae esperanza.
  4. Te gustaria aprender mas?

Reference sheet: Simple Gospel Vocabulary

Guided practice (retrieval)

Say each line out loud from memory before looking back up:

Prompt A

God loves us.

Prompt B

Jesus Christ helps us.

Prompt C

Faith brings hope.

Prompt D

Would you like to learn more?

Say the four lines with a pause after each one. Let the listener respond.

End-of-lesson assessment

Type each answer from memory. Mastery target for this lesson: 4/4.

Primary source for this lesson

Use Preach My Gospel, especially the message about Jesus Christ, for accurate and respectful gospel language.

Why this source: official, mission-focused, and designed for clear conversations.

Spaced follow-up (tomorrow, 3 minutes)

  • Say the four statements from memory.
  • Explain one statement in one simple sentence.
  • Review any missed line and ask the final question naturally.
Ask follow-up questions: Ask your teacher-agent for a respectful gospel vocabulary roleplay.
