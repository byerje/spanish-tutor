Lesson 0006: Daily Routine

Target time: 5-10 minutes. Mission link: describe a few ordinary actions in a simple sequence.

Tangible win for today: You can say when you wake up, eat breakfast, study, and go to bed.

Knowledge (keep it light)

Memorize this mini-sequence:

  1. Me despierto a las seis.
  2. Desayuno a las siete.
  3. Estudio espanol por la manana.
  4. Me acuesto a las diez.

Reference sheet: Daily Routine

Guided practice (retrieval)

Say each line out loud from memory before looking back up:

Prompt A

I wake up at six.

Prompt B

I eat breakfast at seven.

Prompt C

I study Spanish in the morning.

Prompt D

I go to bed at ten.

Change one time and one activity to match your real routine. Say the sequence twice.

End-of-lesson assessment

Type each answer from memory. Mastery target for this lesson: 4/4.

Primary source for this lesson

Continue with the early lessons of Language Transfer: Complete Spanish. Repeat each routine phrase out loud.

Why this source: free, structured, speech-first, and practical for quick daily sessions.

Spaced follow-up (tomorrow, 3 minutes)

  • Say the four-line routine from memory twice.
  • Replace the times with your actual times.
  • Review any missed line, then repeat the sequence.
Ask follow-up questions: Ask your teacher-agent for a routine substitution drill or a timed speaking challenge.
