Lesson 0014: Describing People and Things

Target time: 5-10 minutes. Mission link: describe a person, place, or helpful object clearly.

Tangible win for today: You can say who someone is, describe them as kind, identify a nearby place, and ask for confirmation.

Knowledge (keep it light)

Focused concept: simple descriptions with es and esta.

Memorize this mini-exchange:

  1. Quien es ella?
  2. Es una vecina muy amable.
  3. Donde esta la iglesia?
  4. Esta cerca de aqui.

Reference sheet: Describing People and Things

Guided practice (retrieval)

Say each line out loud from memory before looking back up:

Prompt A

Who is she?

Prompt B

She is a very kind neighbor.

Prompt C

Where is the church?

Prompt D

It is near here.

Change vecina to amigo and iglesia to casa. Point as you speak.

End-of-lesson assessment

Type each answer from memory. Mastery target for this lesson: 4/4.

Primary source for this lesson

Listen and repeat with SpanishPod101, then describe objects in the room.

Why this source: structured, beginner-friendly, and practical for quick daily sessions.

Spaced follow-up (tomorrow, 3 minutes)

  • Describe two people respectfully.
  • Describe one place using cerca or lejos.
  • Review any missed line and point while speaking.
Ask follow-up questions: Ask your teacher-agent for a description guessing game.
