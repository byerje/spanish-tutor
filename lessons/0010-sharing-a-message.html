Lesson 0010: Sharing a Message

Target time: 5-10 minutes. Mission link: invite a person to hear a brief message about Jesus Christ.

Tangible win for today: You can ask permission to share, introduce a short message, ask what the person thinks, and offer to return.

Knowledge (keep it light)

Memorize this mini-exchange:

  1. Podemos compartir un mensaje breve?
  2. Es un mensaje sobre Jesucristo.
  3. Que piensa usted?
  4. Podemos regresar otro dia?

Reference sheet: Sharing a Message

Guided practice (retrieval)

Say each line out loud from memory before looking back up:

Prompt A

Can we share a brief message?

Prompt B

It is a message about Jesus Christ.

Prompt C

What do you think? (formal)

Prompt D

Can we come back another day?

Deliver the four lines warmly, then repeat them with a partner twice.

End-of-lesson assessment

Type each answer from memory. Mastery target for this lesson: 4/4.

Primary source for this lesson

Continue with the beginner lessons at SpanishPod101. Practice the invitation with a calm, understandable pace.

Why this source: structured, beginner-friendly, and practical for quick daily sessions.

Spaced follow-up (tomorrow, 3 minutes)

  • Deliver the four-line message twice from memory.
  • Change breve to one true topic you can explain simply.
  • Review any missed line, then repeat the full invitation.
Ask follow-up questions: Ask your teacher-agent for a respectful doorstep roleplay, pronunciation check, or slower-speed drill.
