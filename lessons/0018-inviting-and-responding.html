Lesson 0018: Inviting and Responding

Target time: 5-10 minutes. Mission link: invite someone kindly and respond when plans change.

Tangible win for today: You can invite someone to meet, accept, decline respectfully, and suggest another time.

Knowledge (keep it light)

Focused concept: flexible invitations with te gustaria and tal vez.

Memorize this mini-exchange:

  1. Te gustaria tomar un cafe?
  2. Si, me gustaria mucho.
  3. Lo siento, hoy no puedo.
  4. Tal vez manana por la tarde?

Reference sheet: Inviting and Responding

Guided practice (retrieval)

Say each line out loud from memory before looking back up:

Prompt A

Would you like to have coffee?

Prompt B

Yes, I would like that very much.

Prompt C

I am sorry, I cannot today.

Prompt D

Maybe tomorrow afternoon?

Swap cafe for caminar or hablar. Practice both accepting and declining.

End-of-lesson assessment

Type each answer from memory. Mastery target for this lesson: 4/4.

Primary source for this lesson

Repeat invitation patterns with Language Transfer: Complete Spanish, then practice a warm, unhurried tone.

Why this source: free, structured, speech-first, and practical for quick daily sessions.

Spaced follow-up (tomorrow, 3 minutes)

  • Make one real invitation aloud.
  • Practice one yes and one no response.
  • Review any missed line and offer another time.
Ask follow-up questions: Ask your teacher-agent for an invitation roleplay with surprises.
